## 2. 符号说明（与 `chapter1_levels.json` 一致）
- `S`：大橘起点 · `G`：被困小猫终点 · `B`：可推重物（纸箱/花盆/洗衣篮） · `F`：小鱼干（每关3条）
- `#`：灌木/围栏墙 · `~`：小水坑（把 `B` 推入 `~` 后变成可通行木桥 `_`） · `D`：打盹看门狗（视线沿指定方向延伸，遇到 `#` 或 `B` 会被挡住）

## 3. 逐关平面图与设计意图

### 1-1 初出纸箱（6×6）
- **意图**：开局 30 秒内用空间布局自然引导玩家走 Z 字形拿全 3 条小鱼干，无任何失败可能。
```
######
#S.F.#
###.##
#.F.F#
#.##G#
######
```

### 1-2 挡路的大纸箱（6×6）
- **意图**：唯一的通道被纸箱 `B` 挡住，玩家把 `B` 向下或向右推开，立刻救出小猫（额外第3条鱼干在 `(4,2)`，与 `B` 同排右端）。
```
######
#S.F.#
#.B..#   <- (4,2) 有第3条小鱼干
#.F#.#
#..#G#
######
```

### 1-3 小心墙角！（6×6）
- **意图**：如果玩家把 `(2,2)` 的箱子直接往右推，会被 `#` 卡住；必须先绕到上面/下面推开，或者点一次免费的「撤销」，学会推箱子的基本空间意识。
```
######
#S...#
#.B#F#
#..#.#
#F.F.G
######
```

### 1-4 小巷里的花盆（7×6）
- **意图**：上方花盆挡路，下方花盆守着 `(5,4)` 的小鱼干小巷，需要按先后顺序清理路线。
```
#######
#S...F#
#.B..##
#..##.#
#F.B..#   <- (5,4) 有第3条小鱼干
#..#.G#
#######
```

### 1-5 推箱填坑（7×6）· ⭐ 第1章核心记忆点
- **意图**：中间 `###~###` 整排灌木加一格水坑把上下区域完全隔开。玩家试着点对岸发现猫怕水过不去，把纸箱 `B` 往下一推掉进 `~` 变成垫脚石，完成第一次"啊哈时刻"。
- **二周目妙解**：获得银小妹（跳）后重玩本关可直接跳过水坑。
```
#######
#S...F#
#..B..#
###~###
#F...F#
#...#G#
#######
```

### 1-6 双箱接力（7×8）
- **意图**：三层花坛被两道水坑隔开，必须先填上层水坑、过桥后把第二只箱子推入下层水坑，并留意不要漏掉左侧的两条小鱼干。
```
#######
#S...F#
#..B..#
###~###
#F.B..#
###~###
#F...G#
#######
```

### 1-7 大橘的抉择（7×7）
- **意图**：手残/佛系玩家直接从下方推箱填坑 6 步即可救出小猫（保底 1★）；想要拿齐 3★ 的玩家需要绕到右上把另一个箱子推进左上小水坑，再折返下层救猫（24 步）。
```
#######
#F#F..#
#~#.B.#
#S....#
#.B####
#.~F.G#
#######
```

### 1-8 花坛迷阵（7×7）
- **意图**：上面的箱子 `(4,1)` 卡着鱼干和回转位，下方箱子 `(3,3)` 需要绕过路口才能往左/往下送进水坑 `(3,4)`，不能乱推堵死自己。
```
#######
#S..B.#
#.#.#F#
#..B..#
###~###
#F..FG#
#######
```

### 1-9 打盹的大黄狗（7×7）
- **意图**：大黄狗 `D` 在 `(3,1)` 向下死死盯住整列通道（直到最下方）。玩家必须把 `(2,2)` 的洗衣篮推到 `(3,2)` 挡住狗的视线，下面的格才全部安全！
- **二周目妙解**：后期用菲菲（盯）可直接定身大黄狗。
```
#######
#S.#D##   D向下盯住 (3,2)~(3,6)
#.B...#
#....F#
#F###.#
#...FG#
#######
```

### 1-10 大救援：外机上的银小妹（8×8）· ⭐ 章末大救援
- **意图**：综合考验第 1 章全部技巧——① 把上方的纸箱推到 `(4,2)` 挡住大黄狗 `D` 的视线；② 绕到中间把第二只箱子推下 `(3,4)` 填平水坑，同时顺路拿走右侧小鱼干；③ 过桥后推开下层的花盆抢救终点外机旁的 **银小妹**！
```
########
#S.#D###  D向下盯住 (4,2)(4,3)
#.B....#
#..B..F#
###~####
#F..B.F#
#..#..G#
########
```
